# S50 KSPO

Full app file is too large for the Git connector payload.

## Deploy the complete app (body map, OSC gear, warmup)

1. Download `S50.html`
2. Open https://vercel.com/muzly/s50-kspo
3. Settings → Deployment Protection → turn **Vercel Authentication OFF** for Production
4. Deployments → Create Deployment → upload a folder that contains only `index.html` (rename S50.html → index.html)
5. Phone: open the production URL → Share → Add to Home Screen
